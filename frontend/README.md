# CivicResolve — Frontend Application

React 19 + Vite frontend client for CivicResolve, an AI-powered civic issue reporting and resolution platform.

## Features
- **Citizen Portal**: Fast, intuitive civic grievance reporting with photo evidence upload and HTML5 GPS geolocation.
- **Complaint Tracking**: Live status lifecycle tracking with real-time AI triage summaries.
- **Municipal Operations Dashboard**: Triage, dispatch, and lifecycle management for municipal teams.
- **Department Performance Analytics**: Recharts-powered SLA metrics, resolution velocity, and operational performance scorecards.
- **Geographic Hotspot Intelligence**: Leaflet OpenStreetMap with distance-based spatial clustering (Haversine formula), heatmaps, and hazard alerting.
